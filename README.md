3D CAD で設計した作品の STL ファイルを1つ読み込むだけで，3つのアプリで同じモデルを使い回し，
**形を確かめる → 強さを予想する → 木取り図を作る** までを一続きで学習できる，ブラウザ完結型の教材アプリです。
インストール・サーバー・ログインは不要です。

---

## 1. 概要（利用場面と構成）

**主な利用場面**：3D CAD（Tinkercad・Fusion 等）で製作品を設計した後の，構想の見直し・材料計画の場面。教員研修での体験・教材研究にも利用できます。

※対象の記載は設計・公開時点での利用目安です。他の学年・場面で使う場合は，発達段階や安全性を踏まえて内容を見直してください。

| アプリ | ファイル | できること |
|--------|----------|------------|
| 初期メニュー | `index.html` | STL を読み込み，3アプリへ引き継ぐ（未選択時は標準モデル「ラック」） |
| かさねん | `kasanen.html` / `kasanen.js` | 3Dモデルをカメラ映像・静止画に重ね，形・大きさ・見え方を確認（STL／GLB／glTF） |
| つよいん | `strength.html` / `strength.js`（計算本体は `kidori.js`） | 本を載せる・横から押すときに，弱くなりそうな部品・接合部・転倒を予想 |
| きどりん | `kidori.html` / `kidori.js` | STL を部品に分解して板の上に並べ，歩留まり・木目方向・木取り図を作成 |

## 2. データの取扱い（区分B：利用者の端末内でのみ情報を扱うアプリ）

[ギジュツドットコムにおける教育用アプリの公開・授業利用ガイドライン](https://gijyutu.com/main/app_guide)の**区分B**に該当します。

| 情報 | 扱い |
|------|------|
| STLデータ・ファイル名 | 3アプリで共有するため，ブラウザ内（localStorage／sessionStorage／IndexedDB）にのみ保存。外部送信なし |
| 単位設定（mm／cm）・強度確認の条件 | ブラウザ内（localStorage）にのみ保存 |
| カメラ映像・背景画像（かさねん） | 端末内で表示のみ。キャプチャ画像は利用者の端末にダウンロード保存 |
| 木取り図の PDF／PNG | 利用者の操作で端末に保存。クリップボードコピーも端末内 |
| 作成者・運営者が取得する情報 | なし（ログ・アクセス解析・アカウント連携なし） |

- **外部通信**：3D表示・ドラッグ操作用のプログラム（下記ライブラリ）を公開CDNから読み込むのみです。利用者の入力情報や作品データは送信しません。
- **消去方法**：各画面左下の「ⓘ このアプリについて」→「保存データを消去」。または，きどりんの「リセット」（STLと配置を消去），ブラウザの閲覧データ（サイトデータ）の削除。
- **AI使用**：本アプリ開発には生成AIを活用しています。生成AIの出力は作成者が内容・動作を確認しています。アプリ動作中に生成AIは使用していません（外部AIサービスへの送信もありません）。

## 3. 利用上の注意（授業で使う前に）

> 本アプリは，教育目的で作成・公開されています。アプリの表示内容には，誤りや不適切な表現が含まれる場合があります。特に生成AIを活用して作成または動作するアプリでは，生成された内容が正確でない場合があります。学習に用いる際は，教科書，授業資料，信頼できる情報源および教員の説明と照らし合わせてください。
>
> 氏名，生年月日，学校名，住所，連絡先，写真，成績，健康・相談に関する情報など，個人を特定できる情報は，教員の指示及び学校・教育委員会等の規程に基づく場合を除き，外部サービスへ送信又は保存しないでください。

- **STLのファイル名に氏名を入れない**よう指導してください（木取り図・PDF のタイトルに表示され，ブラウザ内にも保存されます）。出席番号等で代用することを推奨します。
- **共用端末**では，授業の最後に「保存データを消去」を行ってください。
- **かさねんのカメラ**では，人の顔・名札・掲示物など個人が分かるものが写らないようにしてください。
- **つよいんの判定は授業用の概算**です。材料はスギ相当の代表値（E=5,880MPa，許容曲げ応力18MPa 等）で固定し，部品を梁要素に近似して計算しています。節・割れ・含水率，接着剤や釘の種類・本数，加工精度，固定条件で実際の強さは変わります。**実物の安全を保証するものではなく，作品の評価を確定するものでもありません。**結果は「設計を比べる・見直すきっかけ」として扱い，実際の試作・確認と組み合わせてください。
- 授業前に，使用する端末・ブラウザ・校内ネットワーク（CDN への接続）で動作を確認してください。
- 不適切な表示や不具合が出た場合は，利用を中止し，[問い合わせ](https://gijyutu.com/main/inquiry)からお知らせください。

## 4. 使い方

### 起動
ZIP は必ず「すべて展開」してから，`index.html` をブラウザで開きます（サーバー不要。GitHub Pages 等の静的ホスティングにもそのまま配置可）。
初期メニューで STL を選ぶと，かさねん・つよいん・きどりんの間を移動しても同じ STL が引き継がれます。

### STL の準備
3D CAD で作品を **部品を組み立てた状態（全体をグループ化しない）** で STL にエクスポートします。グループ化すると部品に分解できません。

### かさねん（形を確かめる）
- 「カメラ背景」「静止画背景」で実際の場所にモデルを重ねて，大きさ・見え方を確認
- 「寸法表示」で W・H・D，「STL部品区別」で部品ごとの色分け，「キャプチャ」で画像保存

### つよいん（強さを予想する）
- かんたん設定：力のかけ方（上から／左から／右から），力の大きさ（軽い2kg／ふつう5kg／重い10kg：技術の教科書1冊約500g換算），つなぎ方（接着剤／釘／接着剤＋釘）
- 判定：**余裕あり（緑）／確かめたい（黄）／見直したい（赤）**。「弱そうなところ・なぜ？・どう直す？」を表示
- 荷重スライダーで重さを変えると，判定・色・3Dのたわみ表示が連動。上からの力では「判定が変わる重さの目安」も表示
- 支え方（両端支持・片持ち・支えのある天板・側板の付け根・横ゆれ・転倒）は STL 形状から自動判定。詳しい設定は「先生・発展学習向けの詳しい設定」から変更可能

### きどりん（木取り図を作る）
1. 板の長さ・幅・部品の間隔（切りしろ）を設定し「レイアウト初期化」。必要に応じて「板を追加」
2. 部品をドラッグで配置。右クリック／ダブルクリック／ダブルタップで 90° 回転
3. 「レイアウト決定」で整列し，切断線（赤点線）と寸法線を表示
4. 「木取り図表示」で A4 横 1 ページ（木取り図・歩留まり・木取りの注意・部品表）を表示し，PDF／PNG 保存・クリップボードコピー

| 学習支援パネル | 内容 |
|----------------|------|
| 板の歩留まり | 板ごと・全体の材料利用率（部品面積 ÷ 板面積） |
| 木取りの注意 | 部品の長辺が木目方向（板の長手方向）と合わない場合，板からはみ出す場合に警告 |
| 部品表 | 形状ごとの寸法・個数 |
